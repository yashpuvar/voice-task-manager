# 🎙️ Voice-Controlled Task Manager

A full-stack application that manages tasks using voice commands powered by Google Gemini AI.

## 🛠️ Project Structure
- **/frontend**: React.js (Vite), Web Speech API, Axios
- **/backend**: Node.js, Express.js, MongoDB, Google Gemini API

## 🚀 How to Run Locally

### 1. Backend Setup
```bash
cd backend
npm install
# Create a .env file with GEMINI_API_KEY and MONGO_URI
npm run dev
